Getting Started

1. Installation

To install My Game Engine, follow these steps:

npm install my-game-engine

Alternatively, you can download the latest release from our GitHub page.

2. Your First Project

Create a new project directory and initialize it:

mkdir my-first-game
cd my-first-game
my-engine init

This will set up a basic project structure with a game.js file.

Core Concepts

Scenes

Games are organized into Scenes. Each scene represents a distinct part of your game, like a main menu, a level, or a game over screen.


import { Scene } from 'my-game-engine';

class MyGameScene extends Scene {
    constructor() {
        super();
        this.player = null;
    }

    preload() {
        // Load assets here
        this.load.image('player', 'assets/player.png');
    }

    create() {
        // Create game objects here
        this.player = this.add.sprite(100, 100, 'player');
    }

    update(deltaTime) {
        // Game logic goes here
        this.player.x += 50 * deltaTime;
    }
}

Game Objects

Game Objects are the building blocks of your scene, such as sprites, text, and other interactive elements.


// Creating a text object
const scoreText = this.add.text(10, 10, 'Score: 0', {
    fontFamily: 'Arial',
    fontSize: '24px',
    fill: '#ffffff'
});

API Reference

Detailed documentation for all classes, methods, and properties.

Engine Class

The main class to initialize and run your game.

  • new Engine(config): Creates a new engine instance.
  • engine.start(): Starts the game loop.
  • engine.stop(): Stops the game loop.

Scene Class

Base class for all game scenes.

  • scene.preload(): (Lifecycle method) Called to load assets.
  • scene.create(): (Lifecycle method) Called to create game objects.
  • scene.update(deltaTime): (Lifecycle method) Called every frame for game logic.
  • scene.add: Factory for creating game objects.
  • scene.load: Asset loader instance.
